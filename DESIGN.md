# Bulls and Cows — дизайн проекта

## Данные и алгоритмы

Секрет и попытка хранятся строками, чтобы сохранять ведущие нули.
Раунд содержит секрет, систему счисления, время начала и окончания,
а также массив попыток. `submitGuess` создаёт новый объект раунда
и добавляет попытку через `[...round.history, entry]`.

`evaluateGuess` приводит символы к одному регистру. Затем `filter`
считает совпадения по позициям, а `Set` помогает найти все общие
символы. Коровы — это общие символы за вычетом быков. Попытка
проверяется на уникальность перед подсчётом.

`countPossibleSecrets` рекурсивно умножает число вариантов для
текущей позиции на число вариантов для оставшихся. Для нулевой
длины возвращается `1`. Результаты кешируются в `Map` по длине
и основанию системы счисления.

## Сложность

Пусть `n` — длина кода, а `b` — размер алфавита.

- `generateSecret` — O(b + n × b) в худшем случае. Создание
  алфавита занимает O(b), а `splice` может сдвигать оставшиеся
  цифры после каждого из `n` выборов.
- `evaluateGuess` — O(n) в среднем. Проходим по строкам и проверяем
  наличие символов через `Set`.
- `isValidGuess` — O(b + n × b) для переменного алфавита.
  Проверяем каждый символ через `includes` и уникальность через
  `Set`. В игре алфавит ограничен 16 символами, поэтому это O(n).
- `countPossibleSecrets` — O(n) для нового расчёта и O(1) в среднем
  для уже закешированной пары.

## Принципы чистого кода

- Разделение ответственности. `round.ts` управляет состоянием
  игры, `main.ts` обновляет DOM, а `records.ts` хранит рекорды.
- Повторное использование. `createDigitValidator` используется
  и в `isValidGuess`, и при фильтрации ввода в `main.ts`.
- Явные зависимости. `generateSecret` принимает источник
  случайности, а `startRound` и `submitGuess` принимают время.
  Поэтому тесты могут передавать заранее известные значения.
